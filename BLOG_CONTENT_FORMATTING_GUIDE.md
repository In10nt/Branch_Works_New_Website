# 📝 Blog Content Formatting Guide

## Overview

All blog detail pages now use the **exact same structure, fonts, gaps, and spacing** as the Finance blog. This guide shows you how to format your blog content in the admin panel.

---

## ✅ Formatting Rules

### 1. Headings

**Input:**
```
# Main Heading

## Subheading

### Smaller Heading
```

**Result:**
- Large, bold heading with proper spacing
- Font: Inter, 22px, weight 600
- Margin: 40px top, 24px bottom

---

### 2. Paragraphs

**Input:**
```
This is the first paragraph.

This is the second paragraph.
```

**Rules:**
- Use **double line breaks** (`\n\n`) between paragraphs
- Each paragraph gets proper spacing
- Font: Inter, 16px, color #737373
- Line height: 24px

---

### 3. Lists

**Input:**
```
- First item
- Second item
- Third item
```

**Or:**
```
* First item
* Second item
* Third item
```

**Result:**
- Bulleted list with proper indentation
- Font: Inter, 16px, color #737373
- 8px spacing between items
- 24px left padding

---

### 4. Introduction Paragraph (Optional)

**Input:**
Add excerpt in the "Excerpt" field (not in content)

**Result:**
- Displays as intro paragraph with special styling
- Slightly different color for emphasis

### Fonts
- **All text:** Inter font family

- **Paragraphs:** 16px, weight 400, color #737373
- **Lists:** 16px, weight 400, color #737373

### Spacing
- **Between paragraphs:** 24px
- **After headings:** 24px
- **Before headings:** 40px

- **List indentation:** 24px

### Line Heights
- **Headings:** 30px
- **Paragraphs:** 24px
- **Lists:** 24px

---

## ✅ Best Practices

### DO:
✅ Use double line breaks between paragraphs
✅ Start headings with # symbols
✅ Use - or * for list items
✅ Keep content clear and readable
✅ Write meaningful excerpts

### DON'T:
❌ Use single line breaks (won't create new paragraph)
❌ Mix heading styles inconsistently
❌ Create very long paragraphs (break them up)
❌ Forget to add excerpt (it's the intro)

## 🎯 Quick Reference

| Element | Syntax | Result |
|---------|--------|--------|
| **Heading** | `# Title` | Large bold heading |
| **Subheading** | `## Title` | Medium bold heading |
| **Paragraph** | `Text\n\nText` | Separate paragraphs |
| **List** | `- Item` or `* Item` | Bulleted list |
| **Excerpt** | Use "Excerpt" field | Intro paragraph |

## 💡 Tips for Great Content

1. **Start with a strong intro** - Use the excerpt field
2. **Use headings to organize** - Break content into sections
3. **Keep paragraphs short** - 2-4 sentences each
4. **Use lists for key points** - Easier to scan
5. **End with a call to action** - Encourage engagement

---

## 🆘 Troubleshooting

### Problem: Paragraphs not separating
**Solution:** Use double line breaks (`\n\n`) not single

### Problem: Lists not formatting
**Solution:** Ensure each item starts with `-` or `*`

### Problem: Headings not showing
**Solution:** Make sure `#` is at the start of the line

### Problem: Content looks different from Finance blog
**Solution:** Check you're using the correct formatting syntax
