📌 FIRST TIME SETUP (ONE TIME ONLY)
═══════════════════════════════════════════════════════════════════

Step 1: Install main website dependencies
   npm install

Step 2: Setup admin panel
   setup-admin.bat

═══════════════════════════════════════════════════════════════════

🎯 DAILY USE - SUPER SIMPLE!
═══════════════════════════════════════════════════════════════════

TO START:
   Double-click: start-all.bat
   
TO STOP:
   Double-click: stop-all.bat

═══════════════════════════════════════════════════════════════════

🌐 ACCESS URLS
═══════════════════════════════════════════════════════════════════

Website:      http://localhost:3000
Admin Panel:  http://localhost:5000/admin/  (click "Admin" in footer)
Backend API:  http://localhost:5000/api

═══════════════════════════════════════════════════════════════════

✨ ADMIN PANEL FEATURES
═══════════════════════════════════════════════════════════════════

✅ Dashboard with statistics
✅ Blog Management (create, edit, delete, publish)
✅ Career Management (post, edit, delete, activate)
✅ Rich text editor
✅ No login required (development mode)

═══════════════════════════════════════════════════════════════════

📝 HOW IT WORKS
═══════════════════════════════════════════════════════════════════

1. Admin panel is built as React app
2. Deployed to backend's static folder
3. Served by Spring Boot at /admin/
4. Makes API calls to backend
5. No separate server needed!

═══════════════════════════════════════════════════════════════════

🔧 IF ADMIN LINK DOESN'T WORK
═══════════════════════════════════════════════════════════════════

Run this command:
   setup-admin.bat

This will build and deploy the admin panel.
