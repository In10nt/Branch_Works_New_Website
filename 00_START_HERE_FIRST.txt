📌 FIRST TIME SETUP
═══════════════════════════════════════════════════════════════════

1. Make sure you have installed:
   ✅ Java 17+
   ✅ Maven 3.6+
   ✅ Node.js 14+
   ✅ Python 3.7+

2. Install React dependencies (ONE TIME ONLY):
   - Open Command Prompt in this folder
   - Run: npm install
   - Wait for installation to complete

═══════════════════════════════════════════════════════════════════

🎯 DAILY USE - SUPER SIMPLE!
═══════════════════════════════════════════════════════════════════

TO START:
---------
1. Double-click: start-all.bat
2. Wait 30-60 seconds
3. Website opens automatically at http://localhost:3000
4. Keep the 3 command windows open!

TO STOP:
--------
1. Double-click: stop-all.bat
2. All services stop automatically

🆘 NEED HELP?
═══════════════════════════════════════════════════════════════════

Problem: Services won't start
Solution: Run stop-all.bat first, then start-all.bat

Problem: Admin panel not loading
Solution: Check if Python server window is open

Problem: Blogs not showing on website
Solution: Check blog status is "Published" and refresh page
