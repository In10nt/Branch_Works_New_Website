🚀 DEPLOYMENT INSTRUCTIONS
═══════════════════════════════════════════════════════════════════

STEP 1: Build Frontend
-----------------------
Command: npm run build

Result: Creates 'build' folder with:
  - Website files
  - Admin panel at build/admin/
  - All assets and images

STEP 2: Deploy Frontend
------------------------
Upload 'build' folder to any hosting:
  • Netlify (recommended)
  • Vercel
  • AWS Amplify
  • GitHub Pages
  • Any static hosting

Admin panel will be at: https://yourdomain.com/admin/

STEP 3: Deploy Backend
-----------------------
Build: cd backend && mvn clean package
Deploy JAR file to:
  • Heroku
  • AWS Elastic Beanstalk
  • Railway
  • Any Java hosting

STEP 4: Configure
------------------
Update backend CORS to allow your frontend domain
Set environment variables for database
