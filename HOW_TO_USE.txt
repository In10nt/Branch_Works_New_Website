                    BRANCHWORKS - HOW TO USE
═══════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────┐
│  STEP 1: START THE APPLICATION                                  │
└─────────────────────────────────────────────────────────────────┘

   👉 Double-click: start-all.bat

   What happens:
   ✓ Backend server starts (Port 5000)
   ✓ Admin panel starts (Port 8080)
   ✓ React website starts (Port 3000)
   ✓ Browser opens automatically

   ⏱️ Wait: 30-60 seconds for everything to load

┌─────────────────────────────────────────────────────────────────┐
│  STEP 2: ACCESS THE WEBSITE                                     │
└─────────────────────────────────────────────────────────────────┘

   🌐 Website opens automatically at: http://localhost:3000

   Or manually open browser and go to: http://localhost:3000

┌─────────────────────────────────────────────────────────────────┐
│  STEP 3: ACCESS ADMIN PANEL (Blog Management)                   │
└─────────────────────────────────────────────────────────────────┘

   Option A: From Website
   ----------------------
   1. Scroll to bottom of any page
   2. Click "Admin" link in footer
   3. New tab opens with login page

   Option B: Direct URL
   --------------------
   Open browser and go to: http://localhost:8080

┌─────────────────────────────────────────────────────────────────┐
│  STEP 4: LOGIN TO ADMIN PANEL                                   │
└─────────────────────────────────────────────────────────────────┘

   Username: admin
   Password: admin123

   Click "Sign In"
   
   ✓ Success popup appears
   ✓ Click "Continue to Dashboard" or wait 5 seconds
   ✓ Blog management dashboard opens

┌─────────────────────────────────────────────────────────────────┐
│  STEP 5: MANAGE BLOGS                                           │
└─────────────────────────────────────────────────────────────────┘

   CREATE NEW BLOG:
   ----------------
   1. Click "Create New Blog" button
   2. Fill in:
      • Title: Your blog title
      • Slug: URL-friendly name (e.g., my-blog-post)
      • Category: Finance / Technology Support / Offshore Hiring
      • Content: Your blog text
      • Image: Upload a picture
      • Status: Draft or Published
   3. Click "Publish Blog"

   EDIT BLOG:
   ----------
   1. Find blog in list
   2. Click "Edit"
   3. Make changes
   4. Click "Update Blog"

   DELETE BLOG:
   ------------
   1. Find blog in list
   2. Click "Delete"
   3. Confirm deletion

┌─────────────────────────────────────────────────────────────────┐
│  STEP 6: VIEW BLOGS ON WEBSITE                                  │
└─────────────────────────────────────────────────────────────────┘

   1. Go to website: http://localhost:3000
   2. Navigate to page based on blog category:
      • Finance blogs → Finance page
      • Technology Support blogs → Technology Support page
      • Offshore Hiring blogs → Offshore Hiring page
      • All blogs → Blog page or Home page
   3. Scroll to "Customer Stories" section
   4. Your blog appears in cards
   5. Click "Read more" to see full blog

┌─────────────────────────────────────────────────────────────────┐
│  STEP 7: STOP THE APPLICATION                                   │
└─────────────────────────────────────────────────────────────────┘

   👉 Double-click: stop-all.bat

   What happens:
   ✓ All services stop automatically
   ✓ Command windows close
   ✓ Application shuts down cleanly

═══════════════════════════════════════════════════════════════════

⚠️  IMPORTANT REMINDERS
═══════════════════════════════════════════════════════════════════

✅ Keep all 3 command windows OPEN while using the app
✅ Wait 30-60 seconds after starting before accessing admin panel
✅ Always use stop-all.bat to properly close the application
✅ Set blog status to "Published" to show on website
✅ Choose correct category for blogs to appear on right pages

❌ Don't close command windows manually
❌ Don't start if already running
❌ Don't use ports 3000, 5000, 8080 for other applications
