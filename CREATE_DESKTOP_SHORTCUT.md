# 🖥️ Create Desktop Shortcut for Easy Access

## Option 1: Create Shortcut to start-all.bat

### Steps:
1. Right-click on `start-all.bat` in this folder
2. Select **"Send to"** → **"Desktop (create shortcut)"**
3. A shortcut appears on your desktop
4. **Rename it** to "Start BranchWorks"
5. Double-click the shortcut anytime to start all services

### Optional: Change Icon
1. Right-click the desktop shortcut
2. Select **"Properties"**
3. Click **"Change Icon"** button
4. Choose an icon you like
5. Click **"OK"** → **"Apply"** → **"OK"**

## Option 2: Pin to Taskbar (Windows 10/11)

### Steps:
1. Right-click on `start-all.bat`
2. Select **"Create shortcut"**
3. Right-click the new shortcut
4. Select **"Pin to taskbar"**
5. Now you can start BranchWorks from your taskbar!

## Option 3: Create Start Menu Shortcut

### Steps:
1. Press `Windows Key + R`
2. Type: `shell:programs`
3. Press Enter
4. Create a new folder called "BranchWorks"
5. Copy `start-all.bat` into this folder
6. Now you can find it in Start Menu → All Programs → BranchWorks

## Quick Access Setup (Recommended)

Create shortcuts for both starting and stopping:

1. **Start Shortcut:**
   - Right-click `start-all.bat`
   - Send to Desktop
   - Rename to "🚀 Start BranchWorks"

2. **Stop Shortcut:**
   - Right-click `stop-all.bat`
   - Send to Desktop
   - Rename to "🛑 Stop BranchWorks"

Now you have easy one-click access to start and stop your application!

## 🎯 Result

After setup, your workflow becomes:
1. Double-click "🚀 Start BranchWorks" on desktop
2. Wait 30 seconds
3. Website opens automatically
4. Work on your blogs
5. Double-click "🛑 Stop BranchWorks" when done

**That's it! Super easy! 🎉**
